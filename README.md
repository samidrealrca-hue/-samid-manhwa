# SAMID MANHWA — Admin v2

تمت إضافة لوحة إدارة محسنة إلى النسخة الأولى.

## الموجود الآن
- إدارة الفصول من داخل الموقع.
- إضافة فصل.
- معاينة فصل.
- حذف الفصول المضافة.
- إحصائيات بسيطة.
- تبويبات للإدارة.
- واجهة RTL متجاوبة.

## مهم
هذه ما زالت نسخة Front-end محلية: بيانات Admin تحفظ في LocalStorage داخل المتصفح وليست قاعدة بيانات على الإنترنت.

## للنسخة الحقيقية
الخطوة التالية هي ربط:
- تسجيل دخول آمن.
- قاعدة بيانات.
- تخزين صور.
- رفع عدة صفحات للفصل وترتيبها.
- نشر الموقع.
